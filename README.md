# 📚 CampusGuard: Next-Gen College Entry and Transport System

# 📝 Abstract
CampusGuard is designed to solve the common challenges faced by educational institutions in managing visitor entries, student outpasses, bus transports, and vehicle movements.
Traditional manual record-keeping methods often lead to errors, inefficiencies, and security risks, while making real-time monitoring almost impossible.

Our solution digitizes and automates these processes by using Flask for backend development and SQLite3 for lightweight, efficient database management.
CampusGuard offers real-time tracking, automated entry logging, dynamic reporting dashboards, and centralized record storage for improving campus security and operational efficiency.

By replacing handwritten logs with a secure, transparent, and scalable system, CampusGuard streamlines campus management operations and supports quick and informed decision-making for authorities.

# 🚀 Key Features
* Visitor Entry Management
* Student Outpass System (with hostel details)
* College Bus Tracking System
* Vehicle Entry Monitoring
* Latecomer Reporting
* Centralized Digital Records
* Real-Time Updates and Reporting Dashboards
* Responsive and User-Friendly Frontend Design

# ⚙️ Technologies Used
* Frontend: HTML, CSS, JavaScript
* Backend: Python Flask
* Database: SQLite3
